# Prototype Screenshots

These images show the actual interface served by the compiled Windows prototype. The displayed synthetic trace was computed locally by the release executable. The captures were made during an automated browser test; they show the interface content rather than Windows window decorations. Browser-test transport was used for that capture, while native local-run and audio behavior were separately confirmed in manual testing.
